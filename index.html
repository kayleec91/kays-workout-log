Connect Google Sheets
Step 1
Create your Google Sheet
Go to sheets.google.com, create a blank spreadsheet named Kay's Workout Log.
Step 2
Add the Apps Script
Click Extensions → Apps Script. Delete everything, paste the entire apps-script.js file, save, then Deploy → New Deployment → Web App → Anyone → Deploy. Copy the URL.
Step 3
Paste URL below AND in the HTML file
Paste here to use on this device. Then open index.html in a text editor, find SHEET_URL = '' near the top and paste it there too. Re-upload to GitHub. That way every device has it automatically.
